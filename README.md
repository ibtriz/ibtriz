### <img align="left" alt="•" height="30" src="img/png/blue_luma__super_mario_galaxy__png_by_sylvanbey_dfwxwsw-pre.png"> who am i

**QA Engineer** at Itaú Unibanco, transitioning toward **Backend Engineering**.

My background in test automation and software quality shapes how I approach engineering: understanding systems, questioning assumptions, and treating reliability as a **design constraint**.

Driven by:

- **shift-left testing**
- understanding architecture before writing code — and designing it too
- building quality as part of the product itself, not bolted on afterward
- using the end user as the real acceptance criteria

My experience finding edge cases motivates me to move beyond validating systems and contribute to building them.
